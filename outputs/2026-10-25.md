### TOP1 Piano2Pop: Expanding Piano Demos into Pop Productions Without Aligned Supervision

- 作者：Yun-Chen Cheng, Chih-Pin Tan, Tzu-Hung Huang, Yi-Hsuan Yang
- 方向分类：音乐生成
- 相关性评分：5
- 链接：https://arxiv.org/abs/2610.31510v1

- 一句话总结：论文提出 Piano2Pop 任务，通过伪监督方法将钢琴 MIDI 扩展为流行器乐制作，并在真实钢琴输入上取得最佳指标。
- 解决了什么问题：缺少对齐的钢琴-流行音乐监督数据，难以训练钢琴 MIDI 到流行编曲的扩展模型。
- 核心方法：基于预训练流匹配模型，以钢琴卷帘为条件，利用从流行录音生成的合成钢琴-器乐配对进行伪监督训练；对比无配对转录增强（FST、RDA）与配对监督钢琴翻奏生成器作为伪演示来源。
- 主要创新点：提出音乐扩展任务 Piano2Pop；引入伪监督方法无需对齐监督；比较包括 FST 与 RDA 增强在内的无配对转录方法，其中 FST 可缓解钢琴过重输出。
- 实验结论：在 476 对真实钢琴翻奏/流行音乐测试对上，配对监督方法在 Frechet Audio Distance、伴奏提示依从性和频谱形状上取得最佳结果；FST 在无配对训练中缓解钢琴过重输出；所有微调系统显著优于零样本基线。
- 可能局限：摘要未明确说明。
- 适合谁读：音乐生成、音频合成与多模态学习研究者。
- 和已有工作的关系：摘要提及基于音乐生成与复音音乐转录的进展，并对比无配对转录增强（FST、RDA）与配对监督钢琴翻奏生成器。
- 对研究的启发：利用合成配对数据进行伪监督，为无对齐监督的音乐扩展任务提供思路；任务特定微调显著优于零样本基线，提示专用模型价值。
- 是否值得精读：是：新任务定义与伪监督方案对无对齐音乐生成有参考意义，且包含真实数据评估与基线对比。

### TOP2 Can an Agent Debug a Web Corpus? Agentic Auditing of Slovak FineWeb2

- 作者：Marek Šuppa, Ivan Vykopal, Jaroslav Kopčan
- 方向分类：其他
- 相关性评分：1
- 链接：https://arxiv.org/abs/2610.31636v1

- 一句话总结：论文使用工具型智能体作为语料调试器审计斯洛伐克语 FineWeb2，发现并验证多个缺陷，包括大规模机器生成内容农场。
- 解决了什么问题：多语言管道如 FineWeb2 对上千种语言使用同一配方，个别语言的失败模式未被预期和发现。
- 核心方法：使用 LLM 一次作为语料调试器而非分类器，通过只读、有预算的 API 探索语料，将每个发现编译成可执行测试，再由母语者验证。
- 主要创新点：提出智能体审计框架，产出可执行测试套件，以低成本发现具体缺陷并解释管道遗漏原因。
- 实验结论：三次运行各花费 $2.21-$2.84，发现七项缺陷；最大为占 5.32% 的机器生成内容农场（1,408,437 篇文档）；盲标签支持 7 项中的 6 项；编译测试套件无 GPU 在 0.7 秒扫描全语料；智能体还贡献精确流行率、经抽查的精度估计、遗漏原因说明和可重用测试；最佳静态采样基线验证更多选择器且成本更低。
- 可能局限：摘要未明确说明。
- 适合谁读：语料库审计、多语言 NLP 与数据质量研究者。
- 和已有工作的关系：与多语言管道（如 FineWeb2）及静态采样基线进行对比。
- 对研究的启发：利用工具型智能体进行一次性审计并生成可复用测试，为大规模语料缺陷发现提供低成本、可解释方案。
- 是否值得精读：否，方向相关性低。

### TOP3 Signed Wasserstein distance for room impulse response comparison

- 作者：Linda Fabiani, Sebastian J. Schlecht, Filip Elvander
- 方向分类：其他
- 相关性评分：1
- 链接：https://arxiv.org/abs/2610.31596v1

- 一句话总结：论文提出基于符号 Wasserstein 距离的房间脉冲响应相似度度量，以应对点式度量对时间偏移敏感的问题，并在房间参数扰动与优化中验证优势。
- 解决了什么问题：房间脉冲响应信号稀疏、快速变化且带符号，传统点式度量对小时移敏感且优化损失面不佳。
- 核心方法：提出基于最优传输的符号 Wasserstein 距离，通过比较信号底层分布的位移而非一一对应来度量 RIR 相似性。
- 主要创新点：将符号 Wasserstein 距离用于 RIR 比较，显式考虑脉冲响应结构；可用于可微 Image-Source 模型中的房间参数优化。
- 实验结论：通过房间参数扰动研究，与常用音频基线指标相比，所提距离在几何评估任务中表现出优势，并在可微 Image-Source 模型中对房间参数优化展现出有前景的性能。
- 可能局限：摘要未明确说明。
- 适合谁读：音频信号处理、房间声学与最优传输研究者。
- 和已有工作的关系：对比常用音频基线指标，并在可微 Image-Source 模型中进行房间参数优化实验。
- 对研究的启发：将最优传输与信号结构结合，用于非对齐信号相似度度量，可为其他稀疏或带符号信号比较提供思路。
- 是否值得精读：否，方向相关性低。
